# Parliamo

Italian speaking tutor in one web page. You speak Italian, the tutor answers aloud, and you get text feedback: corrections, a more natural phrasing and pronunciation hints.

- Speech recognition and voice come from Chrome (it-IT)
- The tutor is Claude, called with your own Anthropic API key, which is stored only in your browser
- Open the GitHub Pages link in Chrome, tap ⚙︎, paste your key, then choose a level and topic
